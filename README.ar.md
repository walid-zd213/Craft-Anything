# Craft Anything (العربية)

محرك تحليل وعكس هندسي خالص بلغة Rust يوفر تطبيق سطح مكتب وواجهة سطر أوامر وخادم MCP.

## ما هو هذا المشروع؟

Craft Anything أداة تحليل تساعدك في فحص ملفات البرامج دون تشغيلها. أشر إلى أي هدف، وقل ماذا تريد، وسيحلله باستخدام أدوات فحص حقيقية، ثم يساعدك في بناء نسخة خاصة بك.

## الميزات الرئيسية

- **دراسة أي شيء:** مواقع إلكترونية، تطبيقات سطح المكتب، تطبيقات الهاتف، الألعاب والملفات
- **بناء نسختك الخاصة:** قل ماذا تريد ("أعد بناء هذا الموقع الإلكتروني") وسيبني وكيل برمجة مشروعًا جديدًا
- **التحقق، لا التخمين:** يتم مقارنة كل بناء بالأصل وتحسينه حتى يتطابق
- **مجهزة للوكلاء:** 320 أداة، كل منها أمر في واجهة سطر الأوامر وأداة في MCP

## التثبيت

المتطلبات:
- Rust 1.97 أو أحدث

```bash
git clone https://github.com/storytold/craft-anything.git
cd craft-anything
cargo run --release -p craft-anything        # تطبيق سطح المكتب
cargo install --path apps/craft-anything-cli  # واجهة سطر الأوامر
craft-anything-cli doctor                     # فحص التثبيت
```

## واجهة المستخدم متعددة اللغات

يدعم التطبيق لغات متعددة تشمل العربية. اختر اللغة من الإعدادات.

## أمثلة على واجهة سطر الأوامر

```sh
craft-anything-cli rebuild https://example.com "أعد بناء هذا الموقع الإلكتروني"
craft-anything-cli rebuild - "لعبة ثعبان بلغة Rust" --rounds 1
craft-anything-cli mcp                              # خادم MCP لأي عميل
craft-anything-cli commands                         # جميع الأدوات
```
