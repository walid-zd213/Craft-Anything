# Craft Anything (العربية)

محرك تحليل وعكس هندسي خالص بلغة Rust —reibt سطح المكتب وواجهة سطر الأوامر وخادم MCP.

## ما هو هذا المشروع؟

Craft Anything أداة تحليل машин逆 engineering تساعدك في فحص ملفات البرامج دون تشغيلها. يدعم تحليل ملفات Divdos، و.NET، وJava، وSQLite، وWebAssembly، وغيرها.

## التثبيت

متطلبات البناء:
- Rust 1.97 أو أحدث

```bash
git clone https://github.com/storytold/craft-anything.git
cd craft-anything
cargo build --release
```

## واجهة المستخدم

يدعم التطبيق واجهة رسومية多语言 تشمل اللغة العربية. تغيير اللغة من الإعدادات.
